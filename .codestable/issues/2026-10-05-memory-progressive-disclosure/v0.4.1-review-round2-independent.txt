## (B) 新一轮对抗审查焦点

- **B1 inject.ts 新逻辑**：前言/注记/指针三分互不重叠，无重复路径；唯一新内容路径是「正文里碰巧整行形如 `_[x]_` 的行会被移出原节」（见 nit-3），内容不丢只换位。
- **B2 renderProgressiveBody 极端输入**：无指针→整篇原样返回；全节指针→前言+注记+指针块；节体只剩注记→该节渲染为裸标题（注记已在 notes 块，无丢失）；空前言→被 `filter(Boolean)` 滤掉。均自洽。
- **B3 anchorTokens 口径**：与 `olderTokens` 严格同源（见 A7）。仅一处边角：pi 的 turn start 可能是 `branch_summary` 条目（`isTurnStartMessage` 含 branchSummary），锚点不可重放，此时回执把它的 token 从 dropping 侧减掉却不计入 carrying 侧（见 residual-1）。
- **B4 两个注入点的 root**：均为 `getProjectRoot`（git toplevel，绝对路径）；子目录 cwd 下返回仓库根，指针指向 `memoryDir(根)`，与写入位置一致。**fail-open 路径也自洽**：git 解析失败时 root=resolve(cwd)，而写入端同样以该 root 落盘，指针与文件仍指向同一处。
- **B5 最可能的生产 bug**：见 residual-1（branch_summary 锚点退化路径）——最坏形态是 successor 拿不到「问题原文」、只有占位标记+半回合尾巴，全靠日志指针强指令兜底；另一候选是 fence 内 `## X` 错切分（nit-4），可把真内容折进指针段。
- **B6 逐字一致**：docs/CHANGELOG/词汇表与代码逐字一致；**README.md 未改齐**（见 important-1）。`git diff --check v0.4.0..HEAD` 干净。

### important
1. **README 仍宣称 handoff 携带摘要** — `README.md:3`「带摘要和 replay-safe 原文窗口的 handoff」、`README.md:26`「旧段摘要 + 最近原文 + replay-safe marker」。v0.4.1 已删整条摘要链，README 是消费方第一眼文档，与版本头条「交接不再生成摘要」逐字冲突；attention.md/词汇规范明文「只改一半算未完成」。影响：用户按 README 预期摘要、按现实拿到指针，信任受损。最小修法：两处改「指针 + 最近原文 + replay-safe marker」，与 CHANGELOG 同轮。

### nit
1. `run.ts:426`：`budget summary` 回执「summary budget ~X per handoff before caps」仍可被读成「每次交接会生成摘要」；分叉是已决，但建议句尾补「(the pass reports this trigger; no summary call reads it)」。
2. `report.ts:371`：root 解析失败时向 `ctx.cwd` 的 `.agents/memory/` 写 errors.log，可能在非项目目录造出游离目录树（本仓 `.agents` 是 tracked 路径，污染风险真实存在）。可接受，但建议落在 `~/.pi/agent` 或放弃写入而非 cwd。
3. `inject.ts:51,88-89`：`DOCUMENT_NOTE_RE = /^_\[[^\]]+\]_$/` 过宽——任何整行 `_[x]_` 都会从原节升格进 notes 块（不丢内容只移位）。最小修法：收紧到两个已知标记前缀（`_[memory truncated` / `_[context truncated`）或只扫最后一节。
4. `inject.ts:54-62`：`splitSections` 不追踪 fenced code block，fence 内一行 `## Index` 会把后续真内容错切进指针节（内容仍在磁盘、指针可达，但注入视角丢节）。被删的 `localizeSummaryHeadings` 恰有 fence 追踪逻辑，可移植。
5. `run.ts:160,181`：下限按 `olderTokens`（含被携带的锚点）判，极端时回执可出现「dropping ~0」而交接照发（单条 ≥8k token 的起始消息被整条锚走）。无害但刺眼；下限宜用 `olderTokens - anchorTokens`。
6. 新收据文案（A1/A2/dropping 行）无逐字断言；建议补 pin，防回退。
