# v0.4.1 修复说明（fix note）

范围同 `release-v0.4.1-evidence.md`。本文件解释每一处改动**为什么在那里**，以及用户可见面的变化与非目标。

## 1. 逐文件 why

### 注入层（新增）

- `shared/lang.ts`：CJK 判定的唯一 owner（handoff 自动判定与两个注入共用同一阈值），避免第二份 CJK 区段漂移。
- `shared/inject.ts`：节级指针渲染。一次遍历里「选节 + 绑定该节指针文本」同点完成，所以一个节要么整段常驻、要么换成它自己的那一行，不可能互相顶替；spec 未命名的节 fail-safe 常驻；没有任何指针时原样返回整篇。前言与文档级注记（截断标记）不属于任何节，恒常驻（审1/审2 后补）；调用方给出项目根时 `path` 渲染为绝对路径（审2 对抗轮：read 按会话 cwd 解析相对路径）。
- `memory/injection.ts`：MEMORY/CONTEXT 的 keep/index 规格（哪节常驻、哪节指针、指令文案、路径）与两个入口函数；`keep` 只声明意图并供覆盖测试（渲染不看它）。
- `memory/report.ts` / `archive/archive.ts`：两个注入点把 MEMORY.md / CONTEXT.md 渲染进系统提示，并传入项目根。

### 交接层（删摘要链）

- `handoff/summary.ts` 整体删除（`git rm`）：模型调用、token-cap 重试、摘要超时。
- `handoff/prompt.ts` 重写：续接 prompt = 前言 + 携带声明 + verify 行 + `## 上一会话信息`（session id / 原始 JSONL / 查日志强指令）+ 文件清单 + 可选待答问题；`HANDOFF.md` = 标题 + 时间 + 项目 + 日志 + 索引 + 文件清单。九节标题本地化映射随摘要删除。
- `handoff/threshold.ts`：删掉摘要模型窗口 cap 与 `SUMMARY_OUTPUT_RESERVE_TOKENS`（阈值只剩窗口末点与计价档位两项），`ThresholdBound` 去掉 `summarizer`。
- `handoff/text.ts`：`SPLIT_TURN_MARKER` 改为 `[turn prefix dropped during handoff]`（旧文案承诺了不存在的摘要）。
- `handoff/run.ts`：续接 prompt 在护栏前构建、预估用自身长度；锚点 token 从「丢弃量」与 floor 判据里减掉（锚点被原文携带，不属被丢弃的中间量）。
- `handoff/language.ts`：`HANDOFF_PROMPT_HEADINGS` 保留，用于识别旧版（含 `## Handoff Summary`）残留 prompt。
- `memory/report.ts` 的 `session_shutdown`：整理失败改为记 `errors.log` 的 `shutdown:consolidate` 键，不再冒泡进 pi 的 runner（现场事实：errors.log 2026-09-22 的栈穿过 `emitSessionShutdownEvent`）；`getProjectRoot` 自身失败时只在 `.agents/memory` 已存在处回退写入。

### 配置与词汇

- `shared/config.ts`：三个 handoff 键的注释改为「触发请求 / 无原文携带 / 本侧不调模型」。
- 键名与动词拼写**保留**（`handoffBudgetSummaryTokens`、`/handoff budget summary`、`handoffThinking`），因为与 dsh 面共享；pi 侧 `handoffThinking` 只剩写路径，已在回执、补全描述与 `docs/configuration.md` 说明。

## 2. 用户可见变化（v0.4.1 起）

| 面 | 旧 | 新 |
| --- | --- | --- |
| 开始回执 | `summarizing ~X …` | `dropping ~X of context, carrying ~Y recent...`（X 已扣锚点） |
| 状态行 | ` · summarize N` / ` · summary budget N` | ` · drop N` / ` · drop budget N` |
| 跳过句 | `nothing older than the recent window to summarize` | `… to drop` |
| 成功回执 | 摘要已写入 | `kept ~Z recent; the dropped prefix stays in its session log` |
| 拒绝句 | summary 词 | handoff 词 |
| `/handoff budget recent off` | `summary only, no recent carry-over` | `no recent carry-over; the file list and the session-log pointer are all that carry` |
| `/handoff thinking` | 声称影响摘要调用 | `stored for the dsh profile; this side calls no model` |
| 失败回执 | 含 `pi auto-compaction still applies` | 去掉该承诺 |
| 重放占位 | `[turn prefix summarized during handoff]` | `[turn prefix dropped during handoff]` |
| 注入块 | 整篇 MEMORY/CONTEXT | 决策节常驻 + 其余一节一行指针 + read-first 强指令 |

## 3. 非目标（明确不做）

> **v0.4.2 更新（owner 决定「全修，无用就退役」）**：下面第一条与第二条已被推翻——`handoffThinking`
> 键与 `/handoff thinking` 动词已退役（pi 侧零行为读者，且 pi 的写本来就会丢弃它），`MIN_SUMMARIZE_TOKENS`
> 已更名为 `MIN_DROP_TOKENS`。见 `CHANGELOG.md` 的 v0.4.2 段与
> `.codestable/audits/2026-10-05-context-cost-and-progressive-disclosure.md` §9.7。其余非目标不变。

- **不给 `handoffThinking` 加读者、也不删键**：与 dsh 共享拼写，删除或改名需要单独决议；现场事实不足以支撑。
- **不重命名 `MIN_SUMMARIZE_TOKENS`**：语义已是「最小可丢弃前缀」，改名要动三处调用与两个测试，收益只是字面。
- **不把交接的 `INDEX.md` 指针改绝对路径**：同一块里已给出原始 JSONL 的绝对路径，successor 必定能找到日志。
- **不做「渲染丢条目就拒绝发布」**：本轮把 regression 行保持为日志（检测器），拒绝策略需要 owner 决定。
- **不引入第二套 tokenizer 或分块摘要**：删摘要链后该预算问题不再存在。
- **不为被删机制保留兼容别名**：pi 的 `RegisteredCommand` 没有 alias 字段，仓规本就是硬切。
