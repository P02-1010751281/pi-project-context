## I-1 fix correctness (threshold.ts)

- **Reach**: the carry is uniform on all three drop paths — zero-prompt (line 395), self-density (408), interval-consistency (416) — each adds `entryImages + unreportedOutput(record, tokens)` to the pending `imageAllowance`, which the next comparison consumes at line 435 (`previous.unreported + imageAllowance`). 5e pins the interval path; I probed the other two with a purpose-built fixture (A at 17,766; B dropped with 2,001 hidden output; C billed 17,766 + text + 2,000): fixed code reads **17,766, sampleIndex 0** on both paths; removing the carry on either path alone flips that probe to **19,778, sampleIndex 1** (false re-anchor), and the no-drop control re-anchors as it should. The probe is sensitive, so the carries are real, not cosmetic.
- **No double-count**: structurally airtight — all drop paths `continue` before the push, an accepted record's own `unreported` is stored in the sample (line 444) and never added to `imageAllowance`, so each reply's hidden output is credited exactly once, in the first comparison after it. A dropped record followed by an accepted one credits the dropped reply via the allowance and the accepted reply via `previous.unreported` — disjoint slots.
- **Images stay credited in the same slot**: `entryImages` rides alongside `unreportedOutput` on every drop path; `plain` only ever counts text, so no overlap with `chars`.
- **No leak across a split**: the reset at line 447 is pinned by 5g (mutation G → exactly 5g reddens). The split discard is sound, not just pinned: content the split left in the branch (a dropped reply's hidden output, an edit-added image) is present in *both* the split sample's prompt and the next one, so it cancels in the post-split Δprompt; content a compaction removed is not billed at all. Verified by reading the split/skip flow including the drop-keeps-split-true case.
- **Reset sample**: `imageAllowance = entryImages` after every accepted push (the reply's own images preload the next interval, correctly, since the next prompt carries them); the reset also fires after an anchor reset, which is right.
